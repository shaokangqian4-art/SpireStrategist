# 全局战略助手 · Global Strategy Assistant

[English](README.md) · [Steam 创意工坊](https://steamcommunity.com/sharedfiles/filedetails/?id=3823884252) · [下载](https://github.com/shaokangqian4-art/SpireStrategist/releases)

面向《杀戮尖塔 2》**单人铁甲战士**的实验性本地战略助手。根据牌组、生命、遗物、金币和地图，为选牌、选路、事件、先古奖励、营火与商店提供建议，也可接管已支持的操作。

**运行不需要 GPT、在线 AI、账号或 API Key。** 判断使用可解释的启发式评分；分数不是胜率。

## 功能与使用

- 默认建议模式，点击“开始接管”接管当前局；“停止接管”立即交还控制。
- 推荐物品高亮、动态路线画线，各有独立显示开关，标记不阻挡鼠标操作。
- 五页界面分类显示建议、局面、循环、显示设置与反馈。局内和主菜单面板支持拖动、收起并保存位置。
- 支持中文和英文，默认跟随游戏语言，可在“显示”或主菜单面板切换。卡牌、事件等名称跟随游戏本身语言。
- 另装兼容的 [CombatSolver（Torch）](https://steamcommunity.com/sharedfiles/filedetails/?id=3790899961) 后可接管战斗及连续随机种子爬塔，支持立即停止、本局结束后停止、最高连胜统计。首次安装默认进阶 0，修改后的难度会保存。
- 赞同、异议与复盘记录保存在本机，不自动上传、不自动训练。反馈包不包含整批对局。

订阅 Steam 创意工坊，或者下载 Release ZIP，把其中 `SpireStrategist` 文件夹放到游戏 `mods` 文件夹，启用模组并重启。手动安装和工坊订阅切换时避免同时保留重复副本。

## 适配范围

开发基准为游戏 **0.111.0 / Windows x64**，战斗联动验证版本为 **CombatSolver 0.50.1**。未安装求解器仍可使用战略建议和部分接管，战斗需手动进行，连续爬塔不可用。求解器是独立模组，我们不修改或翻译其界面。

当前仅支持单人战士。支持额外层数；额外幕和任意其他模组组合不保证兼容。未支持的界面可能等待人工处理。部分隐藏信息通过随机流副本预览，后续结果仍受决策及随机流消耗影响。

评分和遗物模型仍不完整。商店对已建模的关键遗物单独判断，其余遗物可能在预算内随机购买。小批次测试不能证明稳定胜率，流程回归不等于胜率训练。原始 JSON 日志保留稳定标识及原始诊断文本，切换语言不改变决策。
