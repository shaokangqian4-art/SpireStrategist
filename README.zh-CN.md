# 全局战略助手 · 0.6.72

[English](README.md) · [Steam工坊](https://steamcommunity.com/sharedfiles/filedetails/?id=3823884252)

支持战士、猎人、机器人、储君、亡灵契约师的本地战略建议与单人接管。默认只给建议；自动战斗与循环爬塔需要单独安装兼容的CombatSolver，普通建议不依赖求解器。无需GPT、API Key或在线模型。

## 本轮更新

- 保护已投入的储君无色生成、力量多段方向，修复无关联铸剑牌的虚假组件加分；星尘按满足现有资源需求后的余星估值。
- 中后期过渡牌须证明边际价值；储君基础先验使用有来源说明的社区榜单校准，不冒充官方强度结论。
- 重新评估君权自授、类星体、环绕轨道等机制升级；减少健康血量下因石炉加湿器过度休息。
- 修复卷轴箱中途接管；五轮书在预算允许时先于已推荐卡牌购买；收紧大蘑菇条件，略提高储君第一幕精英意愿，仍保留生存判断。
- 包含 0.6.56–0.6.71 期间的策略及兼容修正，储君与亡灵契约师仍需实战校准。

## 使用与边界

订阅工坊，或将构建产物SpireStrategist.dll和SpireStrategist.json置于游戏mods/SpireStrategist目录，启用并完整重启。避免手动版与订阅版重复加载。
面板可拖动、收起，双击标题复位；设置页支持跟随游戏、中文或英文。推荐标记不拦截手动操作。

辉眼使用隐藏信息：在原生随机状态副本上作有限条件供牌预测；未来牌不算当前战力。不完整预测未到达事件/先古、跨幕或第三方奖励修改，后续选择可能改变随机流。

多人仅本机建议、标记和记录，可单方安装。禁用接管、自动战斗联动、循环和自动放弃；不建模多人专属牌、队友配合或多人奖励辉眼。原生握手已验证，尚未完成真实双机Steam联机验证。

分数是启发式比较，不是胜率。未知内容可能需要人工处理；部分未知遗物仍有预算内随机购买行为。反馈默认只保存在本地，由玩家导出并分享。
