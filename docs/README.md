# 开发接手入口（0.6.55）

这里记录当前实现与长期约束，代替反复阅读整段聊天。维护日期：2026-11-01。历史版本记录仍保留在根 README 和 `资料/`，不能把历史偏好直接当成现行规则。

## 当前产品状态

- 模组：全局战略助手 / Global Strategy Assistant；ID：`SpireStrategist`；作者：穷仔；MIT。
- 铁甲战士、故障机器人均为正式支持角色。机器人阶段结档：保留现有策略、回归与问题记录，接下来优先通用功能及其他角色。正式支持不等于保证胜率，也不代表所有第三方效果已建模。
- 单人提供建议与接管；自动战斗及循环爬塔依赖单独安装的 CombatSolver。助手不包含求解器，不承担求解器的翻译工作。
- 多人仅本机建议、推荐标记和记录；禁止接管、循环、自动放弃，忽略多人专属牌。仅房主、仅非房主、双方安装的原生握手检查均已覆盖；真实双机 Steam 联机仍需人工验证。
- 猎人本地已完成[机制模型与全局接管接入](silent-model.md)。0.6.53 同时完成[储君和亡灵契约师](regent-necrobinder-model.md)的首版机制模型与单人全局接管；共五个原生角色可选。新增角色仍待自然样本校准，不宣称已训练完成或已验证胜率。
- 语言默认跟随游戏：简繁中文用中文，其余语言用英文；设置页可覆盖并保存。作者日常使用中文。
- Steam 现有条目固定为 [3823884252](https://steamcommunity.com/sharedfiles/filedetails/?id=3823884252)，更新此条目，不创建新的重复条目。

## 维护方式

每次修改同时更新规则、对应测试和必要文案；记录“用户偏好 / 已实现 / 仍待验证”的区别。用户重复反馈同一问题时，先回放日志找同一个根因，不连续叠加两次惩罚。旧版本胜率、回放的推荐变化次数、结构测试数量不能当作新版本胜率。

本次新增药水模型来源为当前游戏 0.111.0 原生 `PotionModel` 目录及动态说明；模型参数是可复核的启发式，不是从玩家胜场数直接拟合的强度榜。
